{%- comment -%} 3D-scene carousel: one scene front and centre, the other three receding behind it. The scenes themselves take no pointer input; clicking a receding tile brings it to the front. It advances when the front recording finishes (the client posts `viser-loop`, see the playback hooks in /viser-idle-sway.js) and tells the incoming scene to restart from its first frame (`viser-restart`), so every scene plays through from the beginning while it is in front. Tile i sits in slot (i - current) mod n: slot 0 = front, 1 = right-back, n-1 = left-back, the rest hidden behind the front tile. Layout + rotation live in the script at the end of this file; CSS in the layouts. {%- endcomment -%}
